Shaijad Shaikh — Developer Portfolio

A personal portfolio website showcasing my projects, technical skills, experience, achievements, and background as a Software Developer.

Overview

I built this portfolio to present my work, share the technologies I use, and make it easier for people to learn about my projects and get in touch with me.

The website features a dark, minimal design with responsive layouts, smooth animations, and an interactive chatbot that answers questions about my portfolio.

Features

- Personal Introduction — A brief introduction and overview of my work.
- About Me — My background and interests in software development.
- Featured Projects — Details and screenshots of selected projects.
- Technical Skills — Technologies, programming languages, frameworks, and tools I work with.
- Experience — My professional and project experience.
- Achievements & Activities — Selected achievements, certifications, and activities.
- AI Assistant — A custom portfolio chatbot that answers questions using a local intent-based engine.
- Contact Section — Ways to connect with me.
- Resume Download — Downloadable copy of my resume.
- Responsive Design — Layouts optimized for desktop, tablet, and mobile.
- Animations — Smooth transitions and scroll-based visual effects.

Tech Stack

- Framework: Next.js 16
- Language: TypeScript
- Styling: Tailwind CSS 4
- Animations: Framer Motion
- Icons: Lucide React
- UI: React

Getting Started

Prerequisites

Make sure you have installed:

- Node.js
- npm
- Git

Installation

1. Clone the repository:
   
   git clone https://github.com/shaijad7/shaijad-portfolio.git

2. Navigate to the project directory:
   
   cd shaijad-portfolio

3. Install dependencies:
   
   npm install

4. Start the development server:
   
   npm run dev

5. Open "http://localhost:3000" (http://localhost:3000) in your browser.

Available Scripts

Command| Description
"npm run dev"| Start the development server
"npm run build"| Build the application for production
"npm run start"| Start the production server
"npm run lint"| Run ESLint checks
